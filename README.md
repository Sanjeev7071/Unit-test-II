# JavaScript Unit Testing – mylib

This project demonstrates a simple JavaScript arithmetic library and unit testing using **Mocha** and **Chai**.

## Functions

The `mylib` library provides:

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero error handling

## Project Structure

```text
Unit-test-II/
├── src/
│   └── mylib.js
├── test/
│   └── mylib.assert.test.js
├── main.js
├── package.json
├── package-lock.json
└── .gitignore
```

## Run the Main Program

```bash
node main.js
```

## Run Unit Tests

Install dependencies first:

```bash
npm install
```

Then run:

```bash
npm test
```

The test suite contains **5 tests**, and all tests pass successfully.
